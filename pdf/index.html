01.1 · Combinar

Unir varios PDF

Selecciona dos o más archivos PDF para fusionarlos en uno solo manteniendo el orden de selección.

01.2 · Extraer / Borrar

Extraer páginas

Indica las páginas que quieres conservar (ej: 1,3,5-8) para crear un nuevo PDF limpio.

01.3 · Orientación

Rotar páginas PDF

Gira todas las páginas o un rango específico en sentido horario.

01.4 · Imágenes → PDF

JPG / PNG a PDF

Convierte una o varias fotos en un documento PDF ajustado automáticamente a página.

01.5 · PDF → Imágenes (.ZIP)

Exportar PDF a JPG / PNG en ZIP

Convierte todas las páginas de un PDF en imágenes sueltas empaquetadas en un único archivo .zip.

02.1 · .DOCX → .PDF VECTORIAL

Word a PDF

Maqueta tu .docx conservando tablas, márgenes, fuentes e imágenes y expórtalo como PDF vectorial nítido (elige Guardar como PDF en el diálogo).

02.2 · .PDF → .DOCX ESTRUCTURADO

PDF a Word Editable

Analiza la jerarquía visual del PDF para reconstruir párrafos completos, títulos, negritas, cursivas y columnas en un archivo .docx limpio.

03.1 · Paginación

Numerar páginas

Inserta numeración automática limpia en el pie de todas las páginas del PDF.

03.2 · Protección Anti-Edición

Marca de agua permanente

Funde el texto en los píxeles del documento para que no se pueda seleccionar ni borrar en Word (ideal para DNI o contratos).

03.3 · Encuadre

Recortar márgenes (Crop)

Recorta bordes blancos sobrantes de todas las páginas indicando los puntos a quitar por cada lado.

03.4 · Rúbrica Táctil Visual

Firmar PDF (Posición exacta en vista previa)

1) Sube tu PDF y dibuja tu firma. 2) Toca o arrastra sobre la vista previa para colocar la firma justo donde quieras.

Toca o arrastra sobre la página para mover tu firma
04.1 · Optimización

Comprimir PDF

Reduce el peso del archivo re-codificando páginas y eliminando metadatos ocultos para enviarlo por email o web.

04.2 · Cifrado

Proteger PDF con clave

Añade una contraseña obligatoria de apertura al documento PDF antes de compartirlo.

04.3 · Desbloquear (Unlock PDF)

Quitar contraseña a un PDF

Elimina la clave de un PDF protegido del que conoces la contraseña para abrirlo libremente sin volver a escribirla.

04.4 · Privacidad Visual Irreversible (Redactar)

Censurar zonas dibujando rectángulos

Sube el PDF, elige la página y arrastra con el ratón o dedo sobre los datos sensibles (DNI, teléfono, IBAN). El documento se aplana para destruir el texto subyacente y que no se pueda recuperar en Word.
